# حریم چیست؟

حریم یک پروژه متن‌باز و مستقل است که با هدف آموزش، پیشگیری و افزایش آگاهی در زمینه امنیت دیجیتال ایجاد شده است.

تمرکز فعلی پروژه بر تولید محتوای آموزشی مستند درباره اخاذی جنسی (Sextortion)، مهندسی اجتماعی و حفظ حریم خصوصی در فضای آنلاین است.

ما باور داریم که **دانش، مؤثرترین ابزار برای پیشگیری از آسیب است.**

---

# چرا حریم؟

هر روز افراد زیادی قربانی سوءاستفاده‌های اینترنتی می‌شوند؛
نه به دلیل ناآگاهی یا ضعف، بلکه چون مهاجمان هر روز روش‌های پیچیده‌تری به کار می‌گیرند.

حریم تلاش می‌کند با ارائه محتوای دقیق، مستند و قابل فهم، فاصله میان کاربران و دانش امنیت دیجیتال را کمتر کند.
